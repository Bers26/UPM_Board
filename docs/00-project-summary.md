# Краткое описание проекта

Архив проекта содержит экспорт рабочего Telegram-чата, три версии ТЗ и набор концепт-изображений настольной игры по «Учёным против мифов». Изначально обсуждалась простая карточная механика «миф — научный ответ», но затем проект вырос в кооперативную кризисную стратегию: игроки-учёные перемещаются между информационными площадками, сдерживают распространение мифов, собирают доказательства и повышают критическое мышление аудитории.

Большая часть механик пока не разработана и не проверена, а достроена нейросетью по визуальным концептам. В документах смешаны черновик правил, идеи дополнений, производственный план, маркетинг и краудфандинг. Отсюда противоречия по числу игроков, типу поля, компонентам, уровню сложности, наличию кубиков, соревновательности и целевой аудитории. Ни одна версия ТЗ не утверждена.

Существует один бумажный прототип поля, однако полноценного отчёта о тестировании нет. Наиболее перспективное ядро — распространение мифов по информационным каналам, изменение состояния аудитории, использование разных типов доказательств и взаимодействие учёных через совместный «консилиум».

Следующий этап — минимальный играбельный прототип: одна цель, условия поражения, структура раунда, базовые действия и единая механика опровержения мифа. После серии тестовых партий можно переходить к полноценному GDD, оформлению и производству.
