# Игровое ядро 0.1

Статус: **каркас для проектирования, не утверждённые правила**.

## 1. Замысел партии

Команда учёных должна остановить распространение мифов в информационной среде и перевести достаточную часть аудитории к рациональному восприятию до наступления общего кризиса доверия.

## 2. Минимальная модель поля

- 6–8 связанных информационных площадок;
- на каждой площадке размещаются жетоны мифов и состояния аудитории;
- у команды есть общий трек кризиса;
- у игроков есть ограниченный набор действий на ход.

## 3. Предварительная структура раунда

1. Ход активного учёного.
2. Выполнение базовых действий.
3. Проверка или опровержение мифа.
4. Распространение мифов.
5. Розыгрыш события.
6. Проверка победы и поражения.

## 4. Кандидаты в базовые действия

- перемещение;
- получение доказательства;
- обмен доказательством;
- работа с аудиторией;
- опровержение мифа;
- совместный «консилиум».

Для MVP нужно оставить не более пяти базовых действий.

## 5. Центральная механическая гипотеза

Миф нельзя убрать одним универсальным действием. Игрок должен подобрать подходящий способ аргументации и изменить состояние аудитории. Разные учёные и доказательства должны создавать осмысленные варианты, а не только совпадение цветных значков.

## 6. Предварительная победа

Команда побеждает, если нейтрализует заданное число ключевых мифов и достигает целевого уровня критического мышления аудитории.

## 7. Предварительное поражение

Команда проигрывает, если:

- общий трек кризиса достигает предела;
- происходит слишком много вспышек;
- заканчивается колода времени или событий.

Для первого теста следует выбрать только один основной и один дополнительный способ поражения.

## 8. Минимальный комплект теста

- 1 поле из 6–8 узлов;
- 3 персонажа без сложных персональных планшетов;
- 8–12 карт мифов;
- 12–18 карт доказательств;
- 10 карт событий;
- жетоны мифов, аудитории и кризиса;
- краткая памятка хода.

## 9. Критерии успешного первого теста

- партия завершается по правилам;
- игроки понимают доступные действия;
- минимум дважды возникает содержательный выбор;
- опровержение мифа не сводится к механическому подбору символа;
- можно объяснить, почему команда победила или проиграла.
