# Журнал принятых решений

Утверждёнными считаются только записи в этом файле. Новое решение добавляется с датой, формулировкой и основанием.

## Принято

### 2026-07-26

- Рабочее название проекта: **«Настолка УПМ»**.
- Репозиторий `Bers26/UPM_Board` является основным хранилищем материалов и истории решений.
- Сначала разрабатывается и проверяется минимальный игровой скелет.
- Производство, тираж, краудфандинг и финальное оформление не входят в текущий этап.
- Нейросетевые ТЗ являются историческими исходниками, а не действующей спецификацией.
- Miro может использоваться для совместного проектирования, Screentop.gg — для удалённых тестов; актуальные правила и решения хранятся в репозитории.
