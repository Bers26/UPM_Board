# Настольная игра «Учёные против мифов»

Рабочий репозиторий проекта настольной игры по мотивам форума «Учёные против мифов».

## Текущий статус

Проект находится на стадии разработки минимального игрового прототипа. Готовой и утверждённой игры пока нет: существуют концепт-материалы, несколько нейросетевых вариантов ТЗ и один бумажный макет.

## Ближайшая цель

Собрать и проверить игровой скелет версии 0.1:

- цель партии и условия поражения;
- структура раунда;
- базовые действия игроков;
- распространение мифов;
- единая механика опровержения;
- минимальный набор компонентов.

## Где что лежит

- `docs/` — актуальные рабочие документы и журнал решений;
- `source/` — исторические исходники и очищенная выборка обсуждения;
- `references/` — визуальные концепты;
- `prototypes/` — физические и цифровые прототипы;
- `playtests/` — шаблон и отчёты плейтестов.

## Правило проекта

Утверждёнными считаются только решения, внесённые в [`docs/02-decisions.md`](docs/02-decisions.md). Исходные ТЗ хранятся для истории и не являются действующими правилами.
